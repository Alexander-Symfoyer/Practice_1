Binary Heap = โครงสร้างข้อมูลแบบต้นไม้ที่ใช้จัดการ ค่าสูงสุด/ต่ำสุดอย่างรวดเร็ว

Max Heap → ค่าสูงสุดอยู่บนสุด
Min Heap → ค่าต่ำสุดอยู่บนสุด
ลูกแต่ละ node มีได้ไม่เกิน 2 ตัว
มักเก็บใน vector
C++ ใช้ผ่าน priority_queue
Complexity
top()  → O(1)
push() → O(log n)
pop()  → O(log n)

จำง่าย ๆ:

Heap = หยิบ Max/Min ได้เร็ว
priority_queue = Binary Heap ที่ C++ ทำไว้ให้แล้ว

Insertion sort 
ดังนั้นใน Algorithm นี้ ส่วนด้านขวาจะค่อย ๆ ถูกจัดเรียงให้เรียงจากน้อยไปมาก


Shell sort
Gap ใหญ่ → Sort เป็นกลุ่ม → ลด Gap → Sort ใหม่ → ลด Gap → ... → Gap = 1 → Sorted
และหัวใจของ Shell Sort คือ:
“Move elements closer to their correct positions before doing the final insertion sort.”
พูดง่าย ๆ คือ เอาของไปใกล้บ้านก่อน แล้วค่อยจัดเข้าบ้านจริงตอน G = 1
