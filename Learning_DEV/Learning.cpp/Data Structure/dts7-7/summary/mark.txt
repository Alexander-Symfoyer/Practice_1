Operator Overloading
-คือการบอก C++ ว่า "เมื่อใช้ Operator กับ Object ของ Class นี้ ควรทำอะไร"
-เช่น a + b    ไม่ได้แปลว่าบวกเลขเสมอไป
-แต่อาจหมายถึง
-บวกพิกัด (Point)
-รวมข้อความ (string)
-รวมเวกเตอร์ (Vector)
-รวมเมทริกซ์ (Matrix)
-ทั้งหมดขึ้นอยู่กับว่าเราเขียน operator+ ไว้อย่างไรครับ
