Constructor
------------
- เรียกตอนสร้าง Object
- กำหนดค่าเริ่มต้น
- จองทรัพยากร (new, เปิดไฟล์ ฯลฯ)
- ชื่อเหมือน Class

Destructor
-----------
- เรียกตอน Object ถูกทำลาย
- คืนทรัพยากร (delete, ปิดไฟล์ ฯลฯ)
- ชื่อเหมือน Class แต่มี ~
- มีได้เพียงตัวเดียว
- ไม่มี Parameter
