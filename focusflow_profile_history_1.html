01 / 08
PROFILE · SCREEN 01
Profile Overview
หน้าโปรไฟล์หลัก — stat + achievement + settings
# COMPONENT BREAKDOWN
A
Cover Photo + Avatar
Background image เปลี่ยนได้ — Avatar overlap ขอบล่าง cover
ปุ่ม ✏️ มุมขวาบนของ cover / ปุ่มวงกลมที่ avatar
B
Name + Bio + Tags
Display name Bold / Bio จางกว่า / Tags แสดง subject ที่สนใจ
Tap ที่ section นี้ → navigate to Edit Profile
C
Stats Row (3 ตัวเลขสำคัญ)
⏱ Total Hours / 🔥 Longest Streak / 🍅 Total Pomodoro
ตัวเลขใหญ่ชัด label เล็กอธิบาย — tap เพื่อดู detail
D
Achievement Badges (ล็อก/ปลดล็อก)
แถว 1: ปลดล็อกแล้ว 🔥⚡🏆 — แสดงเต็ม
แถว 2: ยังล็อก ??? — สร้าง curiosity loop
ปุ่ม "ดูทั้งหมด" → navigate to Achievements screen
E
Settings Link (ล่างสุด)
Notification / Dark mode / Export data / About
เป็น list row เล็กๆ ไม่ได้เป็น primary action
💡 UX NOTE
Profile ที่ดีต้องทำให้ user รู้สึก ภูมิใจ ในสิ่งที่ทำมา — Stats และ Badges คือ reward ที่จับต้องได้ ทำให้อยากกลับมาเปิดดูและเรียนต่อ
02 / 08
PROFILE · SCREEN 02
Edit Profile
แก้ไขข้อมูลส่วนตัวทั้งหมด
# COMPONENT BREAKDOWN
A
Top Bar: Back + Title + Save
← Back (ซ้าย) / "Edit Profile" (กลาง) / Save ปุ่มสีหลัก (ขวา)
Save active ก็ต่อเมื่อมีการเปลี่ยนแปลง — ป้องกัน accidental save
B
Cover + Avatar Preview
แสดง preview ก่อน save — กด "เปลี่ยนรูปพื้นหลัง" เปิด image picker
Avatar มีปุ่มวงกลม overlay เพื่อเปลี่ยนได้ทันที
C
Form Fields
Display Name: single line input / Bio: multiline textarea
Focused field = accent color border / Unfocused = subtle border
Character count แสดงใต้ Bio
D
Daily Goal (stepper)
ตั้งเป้าหมายชั่วโมงต่อวัน — stepper + / - หรือ tap แล้ว type
แสดงหน่วย "ชั่วโมง/วัน" ชัดเจน
E
Tags (Subject Labels)
Chip ที่มีอยู่ = กดเพื่อลบ / + = เพิ่ม tag ใหม่
ควร limit ไว้ที่ 4–5 tags เพื่อไม่ให้รกเกินไป
⚠️ UX CAUTION
ถ้า user กด Back โดยไม่ Save และมีการเปลี่ยนแปลง — ต้อง show confirmation dialog "ยกเลิกการเปลี่ยนแปลง?" ก่อน เหมือน Popup_Quit ที่ทำไปแล้ว
03 / 08
PROFILE · SCREEN 03
Achievements
รางวัลและ badge ทั้งหมด
# COMPONENT BREAKDOWN
A
XP Level Bar
Level ปัจจุบัน + progress bar แสดง XP ที่สะสม
"Level 5 — 780 / 1000 XP" ชัดเจน
B
Category Tabs
แบ่งประเภท badge: ทั้งหมด / Streak / Time / Special
ทำให้ filter ดูได้ง่าย ไม่รกตาเกินไป
C
Badge Grid (ปลดล็อก/ล็อก)
ปลดล็อก = สีเต็ม + ชื่อ badge / ล็อก = จาง + "?" + เงื่อนไข
Tap badge ที่ล็อก → popup แสดงวิธีปลดล็อก
D
Active Challenges
challenge ที่กำลังทำอยู่ + progress bar
"เรียน 5 วันติด — 3/5 วัน" → gamification loop
🎮 GAMIFICATION NOTE
Badge ที่ล็อก + แสดงเงื่อนไขการปลดล็อก = Curiosity Loop ทำให้ user อยากเปิดแอปทุกวัน เหมือนระบบ quest ในเกมครับ
04 / 08
HISTORY · SCREEN 04
History Overview
สถิติและประวัติการเรียนภาพรวม
# COMPONENT BREAKDOWN
A
Period Selector (Week / Month / Year)
Segmented tabs สลับ timeframe ได้ทันที
ข้อมูลทั้งหมดด้านล่าง update ตาม period ที่เลือก
B
7-Day Heatmap
กล่อง 7 กล่อง สีเข้ม = เรียนเยอะ / สีจาง = น้อย / เทา = ไม่เรียน
เห็น pattern รายสัปดาห์ได้ทันที
C
Summary Stats (3 cards)
เวลารวม / จำนวน Pomodoro / วันที่เรียน
ตัวเลขใหญ่ชัด เน้น positive metrics
D
Bar Chart (รายวัน)
แกน X = วัน / แกน Y = ชั่วโมง
Tap bar แต่ละอัน → ดู session ของวันนั้น
E
Recent Session List + "ดูทั้งหมด"
แสดง 2–3 session ล่าสุด
ปุ่ม "ดูทั้งหมด" → นำไปหน้า detailed list
💡 DATA NOTE
แสดงแต่ positive metrics เท่านั้น — ไม่แสดงวันที่ "ไม่ได้เรียน" เป็นตัวเลข เพราะจะทำให้รู้สึกผิดแทนที่จะ motivate
05 / 08
HISTORY · SCREEN 05
Session Detail
ดูรายละเอียดของ session แต่ละครั้ง
# COMPONENT BREAKDOWN
A
Session Hero Card
Subject tag + ชื่อ session + วันที่ + Mood emoji
ดูได้ทันทีว่า session นี้คือการเรียนอะไรและรู้สึกยังไง
B
Time Breakdown
เวลาเรียน (น้ำเงิน) vs เวลาพัก (เขียว)
แสดง 2 ตัวเลขเพื่อให้เห็น ratio ที่ดี
C
Pomodoro Timeline
แสดงแต่ละ pomodoro ที่ทำ — เวลาเริ่มและสิ้นสุด
สีเหลือง = ทำเสร็จ / สีเทา = ยกเลิกกลางคัน
D
Focus Quality Score
คะแนนจากจำนวน pomodoro ที่ทำครบ vs ยกเลิก
เป็น % พร้อม label "ดีมาก / โอเค / ต้องพัฒนา"
E
Delete Session (Destructive)
ปุ่มลบ session นี้ — สีแดงจาง อยู่ล่างสุด
Tap → confirmation dialog "ลบ session นี้?" ก่อนเสมอ
